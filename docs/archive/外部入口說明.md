# 外部入口說明

本文件說明 LINE Bot 與 Discord Bot 兩平台、四組入口的設定方式與啟動條件。

---

## LINE Bot

LINE Bot 使用 **HTTP Webhook** 方式運作：LINE Server 收到使用者訊息後，會 POST 到你的 Webhook URL。

### 女友機器人 (GF)

| 項目 | 內容 |
|------|------|
| Webhook URL | `/api/external/line/callback` |
| 環境變數 | `LINE_CHANNEL_ID`、`LINE_CHANNEL_SECRET`、`LINE_CHANNEL_ACCESS_TOKEN` |
| 未設定時 | Controller 回傳 404 |
| 語音功能狀態 | 暫時全面關閉 (為避開免費版 ngrok 攔截頁面警告) |

> **說明：如何還原 LINE 語音回復 (TTS)**
> 
> 為了避開免費版 ngrok 攔截警告（避免導致 LINE 無法正常向 Proxy 請求語音串流），目前程式碼中已預設將 LINE 語音回復關閉。若您使用的是付費版 ngrok、擁有固定公網網域，或想重新開啟，請至 `LineGfService.java` 中將其還原：
> ```java
> boolean voiceEnable = Boolean.TRUE.equals(session.getVoiceEnabled()); // 還原此行
> // boolean voiceEnable = false; // 註解此行
> ```

### 語音日記 (Diary)

| 項目 | 內容 |
|------|------|
| Webhook URL | `/api/external/line/diary/callback` |
| 環境變數 | `LINE_DIARY_CHANNEL_ID`、`LINE_DIARY_CHANNEL_SECRET`、`LINE_DIARY_CHANNEL_ACCESS_TOKEN` |
| 未設定時 | Controller 回傳 404 |

### 設定步驟

1. 前往 [LINE Developers Console](https://developers.line.biz/console/)
2. 建立或選擇一個 Messaging API Channel
3. 取得 Channel ID、Channel Secret、Channel Access Token
4. 填入 `.env` 對應變數
5. 啟動 ngrok，指向 Gateway (`localhost:8000`)
6. 在 LINE 後台 Webhook URL 欄位填入完整路徑（含 ngrok 網域）

範例：
```
女友機器人 → https://your-ngrok.ngrok-free.dev/api/external/line/callback
語音日記   → https://your-ngrok.ngrok-free.dev/api/external/line/diary/callback
```

## Discord Bot

Discord Bot 使用 **WebSocket Gateway** 方式運作：你的程式透過 JDA 主動連線到 Discord，即時接收伺服器事件。

### 女友機器人 (GF)

| 項目 | 內容 |
|------|------|
| 連線方式 | WebSocket（無需開 port、無需 ngrok） |
| 環境變數 | `DISCORD_GF_TOKEN` |
| 未設定時 | JDA Bean 不建立，不連線 |
| 斜線指令 | `/啟用女友對話`、`/女友提示詞`、`/女友名稱`、`/女友頭像`、`/啟用語音`、`/狀態` 等 |

> **自訂女友名稱與頭像**：支援透過 Discord Webhook 自訂顯示名稱與頭像 URL。每個使用者可設定自己的女友名稱 (`/女友名稱 小美`) 與頭像網址 (`/女友頭像 https://...`)，回覆訊息會以自訂名稱/頭像顯示。

### 語音日記 (Diary)

| 項目 | 內容 |
|------|------|
| 連線方式 | WebSocket（無需開 port、無需 ngrok） |
| 環境變數 | `DISCORD_DIARY_TOKEN` |
| 未設定時 | JDA Bean 不建立，不連線 |
| 指令 | `/記錄日記` — 訂閱此頻道，開始接收語音日記 |
| 指令 | `/移除` — 取消訂閱，不再關心此頻道 |

### 語音日記處理流程

```
使用者傳語音到已訂閱頻道
  → Bot 即時回覆「處理中...」
  → (非同步) 音訊 → MinIO → Python STT 語音辨識
  → (非同步) 辨識結果存入 DB
  → (非同步) 透過 Channel Webhook 通知「✓ 已記錄」
```

### 設定步驟

1. 前往 [Discord Developer Portal](https://discord.com/developers/applications)
2. 建立 Application → Bot
3. 複製 Bot Token
4. 填入 `.env` 對應變數
5. 使用 OAuth2 URL Generator 將 Bot 邀請到你的伺服器
6. 賦予必要的權限（Read Messages, Send Messages, Connect, Voice Activity）

## 啟動條件對照

| 入口 | 需要 ngrok | 需要開 port | 需要申請帳號 |
|------|:----------:|:----------:|:----------:|
| LINE 女友 | ✅ 是 | 否 (走 Gateway :8000) | ✅ LINE Channel |
| LINE 日記 | ✅ 是 | 否 (走 Gateway :8000) | ✅ LINE Channel |
| Discord 女友 | ❌ 否 | ❌ 無 | ✅ Discord Bot Token |
| Discord 日記 | ❌ 否 | ❌ 無 | ✅ Discord Bot Token |

---

## 環境變數參考

```ini
# ── LINE 女友機器人 ──
LINE_CHANNEL_ID=
LINE_CHANNEL_SECRET=
LINE_CHANNEL_ACCESS_TOKEN=

# ── LINE 語音日記 ──
LINE_DIARY_CHANNEL_ID=
LINE_DIARY_CHANNEL_SECRET=
LINE_DIARY_CHANNEL_ACCESS_TOKEN=

# ── Discord 女友機器人 ──
DISCORD_GF_TOKEN=

# ── Discord 語音日記 ──
DISCORD_DIARY_TOKEN=
```

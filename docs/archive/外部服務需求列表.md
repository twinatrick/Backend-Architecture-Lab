# 外部服務需求列表 — 使用者自理項目

> 以下服務無法透過程式碼自動配置，需要您（使用者）手動完成才能讓完整功能運作。

---

## 1. LINE Bot

| 項目 | 說明 |
|------|------|
| 註冊平台 | [LINE Developers Console](https://developers.line.biz) |
| 需建立 | Provider → Messaging API channel |
| 需取得的憑證 | `Channel Secret`、`Channel Access Token`（long-lived） |

**填到哪**：`backend-external-api-service/src/main/resources/application.yml`

```yaml
line:
  bot:
    channel-secret: <你的 Channel Secret>
    channel-token: <你的 Channel Access Token>
```

**補充**：
- Webhook URL 需使用 ngrok 產生的公開網址（見第 3 項）
- Webhook 須設定為 `https://<ngrok-url>/callback`
- 需啟用 Webhook（Use webhook = Enabled）

---

## 2. Discord Bot

| 項目 | 說明 |
|------|------|
| 註冊平台 | [Discord Developer Portal](https://discord.com/developers/applications) |
| 需建立 | New Application → Bot |
| 需取得的憑證 | `Bot Token` |
| 需啟用 | **Message Content Intent**（Server Members Intent 視需要） |
| 需操作 | 邀請 Bot 到你的 Discord 伺服器 |

**填到哪**：`backend-external-api-service/src/main/resources/application.yml`

```yaml
discord:
  bot:
    token: <你的 Bot Token>
```

**邀請 URL 範例**（將 `CLIENT_ID` 換成你的 Application ID）：

```
https://discord.com/api/oauth2/authorize?client_id=CLIENT_ID&permissions=3148800&scope=bot
```

---

## 3. ngrok

用於 LINE Webhook 需要公開 HTTPS 網址。

| 項目 | 說明 |
|------|------|
| 註冊平台 | [ngrok.com](https://ngrok.com)（免費即可） |
| 安裝指令 | `winget install ngrok` |
| 啟動指令 | `ngrok http 8010` |
| 啟動後 | 取得 `https://xxxx.ngrok-free.app` |

**用途**：
- LINE Webhook 設定：填入 `https://xxxx.ngrok-free.app/callback`
- ngrok 免費版每次重啟 URL 會變，需手動更新 LINE Webhook settings

---

## 4. Ollama（雲端 LLM）

| 項目 | 說明 |
|------|------|
| 安裝指令 | `winget install ollama`（作為 API 閘道） |
| 使用模型 | `gemma4:31b-cloud`（Ollama Cloud 雲端模型，**無需本地 GPU**） |
| 啟動服務 | `ollama serve`（預設 `localhost:11434`） |
| 驗證 | `curl http://localhost:11434/api/tags` |
| Python config | `backend-ai-py/config.py` 中的 `OLLAMA_BASE_URL`（預設 `http://localhost:11434`） |

> **注意**：已從本地 `qwen:7b-q4_K_M` 切換至雲端 `gemma4:31b-cloud`，避免本地 GPU VRAM 不足導致推理逾時。

---

## 5. GPT-SoVIT（TTS 引擎）

| 項目 | 說明 |
|------|------|
| 說明 | 自行架設 GPT-SoVIT HTTP API 服務 |
| 預設端點 | `http://127.0.0.1:9880/tts`（可在 `tts_service.py` 中調整） |
| 注意 | 若 GPT-SoVIT 不可用，系統會自動 fallback 到 sherpa-onnx VITS |

---

## 6. Conda 環境（Python 服務）

| 項目 | 說明 |
|------|------|
| 建立環境 | `conda env create -f backend-ai-py/environment.yml` |
| 啟動服務 | `cd backend-ai-py && conda run -n backend-ai-py uvicorn main:app --port 5001` |

> 確保 Conda 已安裝（推薦 Miniconda 或 Anaconda）。

---

## 7. MinIO（已內建於 Docker）

`compose.yaml` 已包含 MinIO，無需額外註冊。但需確認：

| 項目 | 檢查 |
|------|------|
| 容器啟動 | `docker compose -f compose.yaml up -d` |
| 預設帳密 | 見 `compose.yaml` 中的 `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD` |
| 控制台 | `http://localhost:9001` |

---

## 快速啟動檢查清單

```
□ LINE Developers → Channel Secret + Token 取得
□ Discord Developer Portal → Bot Token 取得 + Invite
□ ngrok 安裝 + 啟動 → Webhook URL 填入 LINE
□ Ollama 安裝 + 模型下載 + 啟動
□ GPT-SoVIT 服務架設
□ Conda 環境建立 + 啟動 Python 服務
□ Docker Compose 啟動（PostgreSQL + MinIO）
□ Java 全服務啟動（`./mvnw spring-boot:run`）
```

> 以上全部就緒後，即可執行 **Phase 7：整合測試與驗證**。

# ADR 0022：集中工程規範並保留鎖定本地快照

狀態：已接受治理方向；集中庫目前為未發布草案，尚未正式採用。

兩端各自維護工程規範會使共通原則與審查語意逐漸分歧，但若直接刪除本地文件或永遠追最新版，開發者無法離線取得完整規範，變更也可能未經專案遷移驗證。決定由獨立 `engineering-standards` 庫集中維護共通、後端與前端要求，採整庫單一版本、各專案自行鎖定版本與 Profile，保留完整本地快照、來源提交與 SHA-256；例外另列並須核准，業務模型與執行工具留原專案。代價是必須維護發布及明確升版流程，不能只修改消費端副本。目前只建立 `docs/engineering-standards/` 接軌預覽，根規範仍有效；來源授權、衝突與人工脫敏完成並有真實集中庫 commit 後，另行核准採用。快照檢查不接 CI／hooks、不認證來源，也不新增業務品質門禁。治理詞彙在集中庫 CONTEXT 定義，不混入本專案業務詞彙。

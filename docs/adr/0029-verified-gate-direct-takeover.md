# 29. 工具查證閘門直接試行接管

Date: 2026-10-30
Status: Accepted

## Context

PR #183 的唯讀試用已完成 43 檔、13 批，未發現疑點；這不代表人工裁定部署或全部語意工具已驗收。
使用者考量舊引擎本身已有誤報，明確要求先由新引擎取代試用，並表示不需另保留舊正式路徑，回退依 Git 紀錄處理。

## Decision

- 取代 ADR 0027 的影子模式預設與待環境開關啟用策略；正式 `review.py` 只採工具已查證結果及固定 SHA 靜態查證。
- 未查證的原始模型 Finding 不直接決定正式閘門；不另維持雙軌正式決策、舊引擎備援或自動降級路徑。
- 缺少任何批次查證結果、固定 Base／Head 或合法 Finding 時阻擋，不能因新查證失敗就退回舊引擎。
- 確定性政策重新計算最終結論與人工簽核要求，不信任候選回傳的通過旗標；高風險變更仍須人工簽核。
- 預設模式為 `verified`；本地唯讀比較工具仍可使用 `shadow`，但這不是正式入口的舊引擎開關。
- 已知未知語意、證據不足與必要資料故障維持既有待人工／Fail-Closed 規則；不把批准試用解讀為工具能力已完整。
- 回退透過正常 Git 變更與審查流程處理，不重設或覆寫歷史。程式完成不代表已合併或部署到受信任預設分支。

## Consequences

- 正式報告直接標明「工具查證正式閘門」，不再把實際採用的結果稱為不影響閘門的影子候選。
- 不再受舊引擎直接採信模型主張或本機跨版本掃描影響；無完整上下文時可能增加明確的待查證阻擋。
- 人工裁定遠端部署與真實故障備援驗收仍未完成，需持續處理；不能以本次接管決策掩蓋這些限制。

# 個人餐點與私有媒體的一致性邊界

個人飲食紀錄由既有 external-api 服務持有，不新增微服務或容器。餐點是單一品項，消費明細可由同一使用者的多筆餐點共用；店家據點亦為使用者私有，餐點保留使用者自填的歷史快照，避免全站共用店家異動改寫個人歷史。

餐點與圖片分開建立，圖片以後端逐次驗權串流提供，不發放 MinIO 公開或預簽連結。以資料庫中的媒體狀態與持久化清理工作處理 MinIO／資料庫非原子操作；刪除成功代表撤銷存取且清理責任已可靠保存，不代表物件已即刻實體移除。代價是增加狀態與背景重試，而不是讓圖片失敗回滾成功的餐點。

專用 LINE Bot 與本機 OCR 同由此服務承接，LINE 不重用既有日記 Bot，OCR 不將明細送往雲端。Google 店況追蹤僅在背景查詢、保存與通知用途的授權已確認後啟用；保留每季自動追蹤需求，不以爬蟲或人工逐店確認替代，所有相關 API 呼叫受每月預設 1,000 次的保守上限約束。
